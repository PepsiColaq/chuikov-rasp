# Расписание колледжа им. В. И. Чуйкова

Неофициальный студенческий сайт: расписание групп, ДЗ, замены.

**Сайт:** https://pepsicolaq.github.io/chuikov-rasp/

Не является официальным ресурсом колледжа.

## Локальный запуск

```bash
npm install
npm run dev
```

## Деплой на GitHub Pages

```bash
npm run deploy
```

## Данные

Расписание из Excel «1 полугодие» (60 групп). Правки ДЗ/замен пока хранятся в браузере каждого устройства — общая синхронизация (Supabase) подключается отдельно.
