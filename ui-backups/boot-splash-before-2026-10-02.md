# Бэкап UI: заставка с логотипом колледжа (02.10.2026)

Откат:
1. В `src/main.js` поставь `const BOOT_SPLASH = false`
2. В `index.html` можно вернуть простой `<p id="boot">Загрузка расписания…</p>` (не обязательно — при `false` JS всё равно рисует текст)
3. Задеплой.

При `BOOT_SPLASH = false`:
- снова текстовая «Загрузка…» без логотипа и анимации появления.
