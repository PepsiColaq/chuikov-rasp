# Бэкап: без аватаров (до profile avatars, 01.10.2026)

Откат UI: в `src/main.js` поставь `const PROFILE_AVATARS = false` и задеплой.

При `false`:
- в «Ещё» снова только буква в кружке (без кнопок фото);
- в ДЗ нет крошечных аватарок автора.

SQL в базе можно не откатывать — колонки просто не используются клиентом.
