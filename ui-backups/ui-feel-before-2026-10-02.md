# Бэкап UI: отклик + pull-to-refresh + заставка/тосты (02.10.2026)

Пакет «чтобы всё летало». Флаги в `src/main.js`:

- `const UI_MOTION = true` — плавные анимации (раскрытие ДЗ, вкладки, лайтбокс, каскад карточек, индикатор навбара, плавный скролл). Откат: `false`.
- `const UI_FEEL = true` — вибро-отклик на нажатия (navigator.vibrate). Откат: `false`.
- `const PULL_TO_REFRESH = true` — жест «потяни вниз — обновить» на «Парах»/«ДЗ». Откат: `false`.
- `const BOOT_SPLASH = true` — заставка с логотипом (премиум-анимация, показывается один раз за сессию, не блокирует загрузку сетью). Откат: `false` → снова текст «Загрузка…».

Свайп вкладок (02.10.2026, SW v66):
- после свайпа панель назначения **оставляется** (`commitSwipeToTab`), без полного `render()` и без каскада — чтобы не мигало при туда-сюда.
- каскад карточек только при клике в навбаре.
- соседняя вкладка при свайпе строится с `{ cascade: false }`.

Прочее:
- Тосты: `showToast()` / `flash()`.
- Скелетоны ДЗ при `initialDataLoading`.
- F5 без мигания заставки: `public/boot-gate.js` + `sessionStorage rasp_splash_seen_v1`.

Всё уважает `prefers-reduced-motion: reduce`.
